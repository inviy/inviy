**How I build**

- Model output is untrusted input. It is checked for shape and range before it reaches any calculation.
- Choose by measurement. Candidates run on the same fixtures, and the conditions are written down with the result.
- Tests that run without calling a model come first. Pinned regression corpora catch behavior changes.
